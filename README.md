
# SQL Server End-to-End Practice

## 📌 Project Overview

This repository contains a hands-on Microsoft SQL Server project designed to practice SQL concepts from basic to advanced level. It includes database creation, sample data insertion, data validation, SQL queries, data cleaning, and business analysis.

The project is intended for learners preparing for Data Analyst, Power BI Developer, and Data Engineering roles.

## 🎯 Project Objectives

- Learn SQL concepts through practical exercises.
- Practice writing efficient SQL queries.
- Understand database and table management.
- Perform data cleaning and validation.
- Analyze customer, product, and order data.
- Solve real-world business problems using SQL.

## 🛠️ Tools & Technologies

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL
- Git and GitHub

## 📚 SQL Topics Covered

### 1. Database Fundamentals
- Create databases and tables
- Insert sample data
- Primary keys and foreign keys
- Data types and constraints

### 2. Basic SQL Queries
- SELECT and DISTINCT
- WHERE conditions
- ORDER BY
- TOP, OFFSET and FETCH

### 3. Filtering and Operators
- AND, OR and NOT
- IN and BETWEEN
- LIKE and pattern matching
- NULL value handling

### 4. Aggregate Functions
- COUNT(), SUM(), AVG()
- MIN() and MAX()
- GROUP BY
- HAVING

### 5. SQL Functions
- String functions
- Date and time functions
- NULL handling functions
- Type conversion functions
- CASE expressions

### 6. Joins
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL OUTER JOIN
- Multi-table joins

### 7. Subqueries and Set Operators
- Scalar and correlated subqueries
- EXISTS and NOT EXISTS
- UNION and UNION ALL
- INTERSECT and EXCEPT

### 8. Data Modification and Cleaning
- INSERT, UPDATE and DELETE
- ALTER TABLE
- Duplicate detection and removal
- Missing value handling
- Data validation

### 9. Common Table Expressions
- CTEs
- Multiple CTEs
- Recursive CTEs

### 10. Window Functions
- ROW_NUMBER()
- RANK() and DENSE_RANK()

- Running totals and moving averages

### 11. Business Analysis
- Total revenue analysis
- Monthly revenue trends

- Category-wise sales analysis
- Customer purchase analysis

### 12. Advanced SQL Server
- Transactions and error handling
- Views
- Stored procedures
- User-defined functions
- Indexes and execution plans
- Temporary tables and table variables
- PIVOT and dynamic SQL

## ▶️ How to Run the Project

1. Install Microsoft SQL Server and SQL Server Management Studio.
2. Connect to your SQL Server instance.
3. Open `01_Create_Database_And_Tables.sql` and execute it.
4. Run `02_Insert_Sample_Data.sql` to populate the tables.
5. Execute `03_Data_Validation.sql` to verify the data.
6. Open the SQL practice scripts and solve the exercises topic by topic.

**Note:** Execute scripts in the correct order and use test data or transactions when practicing UPDATE and DELETE statements.
